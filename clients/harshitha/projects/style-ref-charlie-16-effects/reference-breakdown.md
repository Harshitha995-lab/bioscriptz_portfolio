# Reference breakdown: Charlie Hills, "Opus 5.5 Motion Graphics" (16 effects)

**What it is.** A 22 s, 4:5-ish board (522 x 644 source) showing 16 looping
motion effects at once, from Charlie's newsletter edition. Every tile is the
`motion-effects` skill already installed in `.claude/skills/motion-effects/`
(recipes in `references/effects.md`). Each tile is an 8 s seamless loop.

**Style.** Light, editorial and product-led: warm off-white paper, ink-navy
dark tiles, one coral-red accent ball and soft blue. Grotesk type, real-looking
UI, small precise movements. The opposite of the dark cosmic launch film,
and just as premium.

| # | Effect | Group | What moves | Fits in a founder / SaaS video as |
|---|---|---|---|---|
| 01 | Button → player | Interface | A Preview button grows into a playing video player | "Watch the demo" beat |
| 02 | Search → results | Interface | Query types, results drop in one by one | "Find anything" / feature beat |
| 03 | Card → workspace | Interface | A small brief card opens into the full editor | Feature announcement |
| 04 | Tabs → panels | Interface | Tabs switch, the panel content swaps | Plans, channels, comparisons |
| 05 | Chart morph | Data | Bar chart morphs into a line with a value tag | Results / growth beat |
| 06 | Dashboard zoom | Data | Camera zooms from dashboard to one KPI card | "The number that matters" |
| 07 | Spring stack | Data | Cards spring forward in turn | Offers, testimonials, case studies |
| 08 | Magnetic dock | Data | Cursor glides, dock icons magnify, label pops | Integrations / tool stack |
| 09 | Masked type | Type | Image or colour revealed through big letters | Title or launch name |
| 10 | Elastic type | Type | Letters stretch and snap back | Event, webinar, podcast opener |
| 11 | Text → layout | Type | A headline rearranges into an article layout | Newsletter / blog teaser |
| 12 | Image reveal | Type | Wipe reveals a product photo | Product drop |
| 13 | Perspective shift | System | Flat layers tilt apart in 3D | Explaining layers of a product or service |
| 14 | Glass focus | System | Frosted glass slides to highlight one row | "Read this line" in a report |
| 15 | Flowing paths | System | One input flows along paths to many outputs | One idea → many channels |
| 16 | Particle logo | System | Dots gather into the logo | End card |

**How to use them with a voiceover.** Each effect is one 2 to 4 s shot. Cut
between effects on the voiceover's beats (one effect per line) and a 60 s
script becomes 15 to 20 shots: the "high motion most of the time" feel of the
launch-film reference, in the client's brand instead of purple.
