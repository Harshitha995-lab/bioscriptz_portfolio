# Client templates

| File | What it is |
|---|---|
| `client-onboarding-form.md` | Master onboarding form to send each new client after the first call |
| `send-over-message.md` | Email and WhatsApp/DM text to send the form with |

## How to use (2 minutes)

1. Copy `client-onboarding-form.md` into a new Google Doc or Notion page (paste as Markdown).
2. Find and replace:
   - `{{FOUNDER_NAME}}` → the founder's first name
   - `{{COMPANY_NAME}}` → their company
   - `{{DUE_DATE}}` → usually 3 days from the call
3. Set sharing to "Anyone with the link can edit".
4. Send it with the message in `send-over-message.md`.
